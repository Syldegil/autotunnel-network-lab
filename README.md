# autotunnel-network-lab

Android DNS/TCP/TLS inspector, network observations, graphical route drafts and an experimental routing/restoration engine. The public application ID is distinct from the private installation. No APK or personal tunnel profile is included.

Experimental sources maintained by Syldegil. [Français](README.fr.md).
